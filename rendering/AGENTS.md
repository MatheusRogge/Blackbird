# rendering

wgpu 30 renderer (Vulkan backend forced). Contains the render graph, every render/compute pass, the deferred PBR + clustered lighting + CSM shadows + DDGI pipeline, the 2D sprite renderer, camera/light entities and the GPU profiler. Depends on `engine_core` and `assets` only. Re-exports `wgpu`.

## Features
- `rendering_2d` (default): the `rendering_2d` module.
- `debug`: `DebugLayer` (an egui `UiLayer` with frame stats + `RenderDebugFlags` toggles/DDGI tuning). Pulls in `egui` + `ui`.

## Render graph

### Building
A `RenderGraphBuilder::build(self, device, surface_config) -> (RenderGraph, ResourceId)` returns the graph and the **output resource id** (the surface, created with `create_external_resource()`).

The pass constructor convention is `XPass::new(&mut graph, upstream_outputs…, shader) -> (XPass, XOutputs)`. The constructor allocates its output resources with `graph.alloc_resource_id(desc)` and returns the ids in an `XOutputs` struct for downstream passes. Then `graph.add_pass(device, pass)` registers it, creates a bind group layout from `layout_entries()` if there is one, and calls `bind_node_id`.

`ResourceDescriptor` variants:
- `ScreenTexture`: sized to the surface and reallocated on resize. **Transient**: screen textures with the same format + usage whose lifetimes in the pass order don't overlap share one physical texture. Contents are undefined after the last reader in a frame, and the first writer must clear or fully overwrite it. A screen texture some pass reads before any pass writes it is never aliased.
- `Texture`: has an explicit size but is *also* resized to the surface on resize.
- `FixedTexture`, `Fixed3DTexture`: never resized.
- `UploadBuffer`: CPU-written (`queue.write_buffer`), GPU **read-only**. Packed with every other `UploadBuffer` into a few `UploadArena` pages on the first `execute` (offsets aligned to the device's uniform/storage offset alignment). The arena is then sealed: adding an `UploadBuffer` later trips a `debug_assert!`. Use this for uniforms, params, light lists, BVH data.
- `Buffer`: a dedicated buffer. Use it for anything bound as `read_write` storage (`light_grid`, `light_indices`, `ray_radiance`, `ray_direction`). wgpu tracks usage per buffer, not per range, so a GPU-written range inside a shared page would conflict with the read-only ranges bound in the same pass.
- `ExternalView`: never allocated. Use `import_texture` / `update_imported`, or it's the surface.

### Executing (`RenderGraph::execute`, every frame)
1. **Compile** (cached, redone after `add_pass` / `add_subgraph`): walk backwards from the output resource, and from every pass whose `has_side_effects()` is true, through `writes()` → `reads()` to find the needed passes, then topologically sort them (Kahn, ties broken by lowest `NodeId`). `reads()` / `writes()` must therefore be static.
2. On the first frame build the `UploadArena`. Every frame, `GeometryArena::sync` uploads new meshes and frees removed ones, and `FrameArena::begin_frame` resets the frame cursor. When a screen texture is unallocated (first frame, resize, graph change), assign and allocate all screen textures through `texture_pool::assign`. Then lazily allocate every other unallocated non-external resource.
3. Rebuild the graph-managed bind group (from `binding_resources()` + `samplers()`) for **every** pass that has one. This happens every frame.
4. For each pass in order, build a `PassContext { views, textures, buffers, bind_group, upstream, surface_size, geometry, frame }` holding only that pass's declared reads + writes. `buffers` holds `BufferRange`s: bind with `.binding()`, write with `.write(queue, ..)` / `.write_at(..)`, slice with `.slice()`. Never use `as_entire_binding()` or offset 0 on a graph buffer, because it may share a page. The output id maps to the swapchain view. Then call `pass.execute(device, queue, encoder, &ctx, world)` wrapped in CPU and GPU timing.
5. Return one `CommandBuffer` and publish `ArenaStats` in `FrameStats.memory`. `Renderer` submits the buffer, plus the overlay buffer if there is one, then calls `schedule_gpu_readback`.

**Rules that follow from this:**
- A pass is **culled** unless something on the path to the output reads a resource it writes, or it returns `has_side_effects() = true` (e.g. `prev_frame`, which only fills a texture read next frame). Every resource a pass touches must appear in `reads()` / `writes()`, or the pass is dropped, misordered, or finds the id missing from `ctx`.
- There is one writer per resource (the `writer_of` map keeps the last one). Ping-pong patterns (DDGI atlases) declare both slots and track the active one with an `Arc<AtomicUsize>`.
- The order of independent passes is deterministic (lowest `NodeId` first), but it's an implementation detail. If one pass must run before another, add a read/write dependency. Texture aliasing is computed from this order.
- A pass-owned uniform should be an `UploadBuffer` declared in the constructor and listed in that pass's own `writes()`, so it lands in `ctx.buffers`. Shadow cascade VPs share one `UploadBuffer` at a 256-byte stride with a dynamic-offset bind group.
- `queue.write_buffer` calls made during `execute` all land before the frame's command buffer runs.
- Most passes build their pipelines **lazily on first execute** and own extra wgpu objects themselves (own bind groups, material texture caches). Graph bind groups are only for the simple case. Pass-cached bind groups that reference screen textures must be dropped in `on_resize`, which is when aliasing is reassigned.

### Arenas
- `GeometryArena` (`ctx.geometry`): one vertex + one index buffer for every `Mesh`, sub-allocated with `offset-allocator`, keyed by `EntityKey`, plus an **instance buffer** of `GpuModel { model, normal, material, base_color, emissive, transmission, attenuation }` (normal = inverse-transpose; `material` = [alpha cutoff or 0, double-sided 0/1, metallic, roughness]; `base_color` = the factor; `emissive.rgb` = emissive factor × strength; `transmission` = [factor, IOR, volume thickness (mesh-local), attenuation distance or 0 for none]; `attenuation.rgb` = volume attenuation color) with one slot per mesh, rewritten from `Mesh::transform` every frame. Each `MeshDraw` also carries the mesh's local-space `bounds`, which `shadow` and `gbuffer` cull with. Bind `vertex_buffer()` / `index_buffer()` and a bind group on `instance_buffer()` (layout `GeometryArena::instance_layout_entry`) once per pass, then `draw_indexed(draw.indices.clone(), draw.base_vertex, draw.instances())` with `ctx.geometry.get(key)`. Shaders read `models[instance_index]` (`gbuffer.wgsl` group 2, `shadow.wgsl` group 1, `lighting.wgsl` group 0 binding 7 for `transparent`; keep the WGSL `Model` structs in sync with `GpuModel`). When full it rebuilds bigger buffers and re-uploads every live mesh (`generation` bumps). Never hold a buffer across frames.
- `FrameArena` (`ctx.frame`): `alloc(device, queue, data, align) -> FrameSlice` for data that changes every frame (sprite instances). It resets each frame. On overflow that frame falls back to a one-off buffer and the arena grows at the next `begin_frame` (`generation` bumps). A bind group built on it must be rebuilt when `generation` changes.

### Writing a new pass
0. If the pass only samples screen textures and uniforms into one output, use `FullscreenPass::new(graph, name, inputs, uniforms, format, shader)` and skip to step 4 (that's how `composite` is built).
1. Create `pass/my_pass.rs` with `struct MyPass { node_id: Option<NodeId>, …ids, shader, pipeline: Option<…> }` and `MyOutputs`.
2. `impl PassDesc` (`name`, `reads`, `writes`, optionally `layout_entries` / `binding_resources` / `samplers`) and `impl Pass` (`bind_node_id`, `execute`, optionally `on_resize`).
3. Add `pub mod my_pass;` to `pass/mod.rs`, wire it in `pbr/builder.rs`, and make sure a downstream pass reads its output.
4. Add the WGSL to `sandbox/shaders/`, pass it through `RenderGraphPBRBuilder::new` (new parameter), and update `sandbox/src/main.rs`, `editor/src/main.rs` **and** `player/src/main.rs`.

## PBR pipeline (`pbr/builder.rs`)

| Pass | Kind | Reads (world / graph) | Writes |
|------|------|------------------------|--------|
| `camera` | upload | first `Camera` | camera uniform (view_proj, inv_view_proj, inv_view, depth_params = (near, far, frame index mod 1024, 0), prev_view_proj = last frame's view_proj, or this frame's on the first). Shaders may declare only a prefix of it |
| `light_upload` | upload | camera + all lights → **view space**, meshes, debug flags | point/spot/area/sky buffers, counts, `ShadowedLights` uniform. Appends one **one-sided area light per flat emissive mesh** (`light::emissive::fit`: area-weighted normal coherence ≥ 0.95, smallest edge-aligned rectangle; cached per mesh `EntityKey`), with luminance = emissive factor × strength × the emissive texture's mean, brightest first after the scene's area lights, skipping < 0.01 lm; off with the `emissive_lights` debug flag. Then scores every local light by flux / (distance to camera² + 1) and hands them to `ShadowSlots` (none with Shadows off), which shadows the top `MAX_SHADOWED_LIGHTS` (32) in the atlas. Spot lights with an outer angle ≤ 60° get one face (field of view = outer cone + 0.1 rad), everything else a cube of six. Tile size follows coverage = range / camera distance: 512² from coverage 1, halving per halving, down to 128², with 25 % hysteresis around each tier so sizes don't flip as the camera moves. A light keeps its slot and tiles while it stays selected with the same shape and size, so reranking doesn't invalidate cached maps. New or resized lights allocate in score order, falling back to smaller tiles; when even 128² doesn't fit, the lowest-ranked shadowed light is evicted, and a light that still doesn't fit goes unshadowed. Writes each light's `shadow_slot`; `count` is one past the last used slot. Range = the light's radius, or for area lights where L·A/d² drops below 0.001 lx (≤ 50); one-sided area lights shadow from 2 cm in front of their emitter |
| `bvh_upload` | CPU build + upload | all non-`Blend` `Mesh`, in world space via `transform`. Rebuilt when the mesh **count** changes, or once transforms have been unchanged for 10 frames after a change (so dragging doesn't rebuild every frame). Each triangle gets its mesh's material factors × the mean of its albedo / metallic-roughness / emissive textures (cached per texture) × the average of its 3 vertex colors | BVH nodes/tris/info |
| `probe_atlas` | upload | camera eye, `RenderDebugFlags` DDGI params | probe grid params (grid snaps to `probe_spacing`, scrolls with the camera) |
| `probe_trace` | compute | BVH, probe params, sky/point/spot/area lights + counts | per-ray radiance + direction (864 probes × 128 rays, every 4th frame). Hits are lit by every light with one any-hit shadow ray each (`bvh_trace(.., any_hit = true)`). Local lights skip the ray when out of range or behind the surface, and the ray stops `SHADOW_BIAS × probe_spacing` short of the light. Area lights use the closest point. Single bounce: hits don't sample the probes. Cost grows with hits × lights in range. Binds 9 storage buffers, over WebGPU's default of 8 (fine with `adapter.limits()` on Vulkan). Hits add the triangle's emissive, so emitters bounce light into GI. Hit albedo is `(1 − metallic)·albedo·(1 − spec) + spec`, where `spec` is the env-BRDF reflectance seen from the probe, spread diffusely |
| `probe_update` | compute | rays, atlas[current] | atlas[1-current] (irradiance 8², visibility 16², 1px border), then flips `current_atlas` |
| `shadow` | raster | first `SkyLight`, camera, all meshes (`Blend` ones only into the glass tint maps) | 4-cascade 2048² depth array + `ShadowParams` (PSSM λ=0.75, sphere-fit, texel-snapped). Each cascade only draws meshes whose bounds reach its ortho box. Splits end at the farthest scene point and each cascade's depth range spans the world-space scene AABB, so shadows work at any scene scale. Opaque meshes use a depth-only, front-face-culled pipeline. `is_masked` meshes use an unculled pipeline (`vs_masked`/`fs_masked`) that alpha-tests albedo. That pipeline keeps its own copies of those meshes' albedo textures (`masked_textures`, keyed by `TextureAsset::id`, with key 0 = white fallback, pruned to live masked meshes every frame) and multiplies their alpha by the base color factor's Then **local light shadows** in a 4096² Depth32Float atlas (`local_shadow_map_id`): for each `ShadowCaster` slot `light_upload` shared this frame, its faces (cube: +X −X +Y −Y +Z −Z at 90°; spot: one face along its direction; near 0.02, far = range) render into their tiles with unculled, depth-biased copies of both pipelines (rooms see walls from both sides), all re-rendered faces in one depth pass with a viewport + scissor per tile. A load-op clear would wipe the atlas, so each tile is first cleared by a triangle at far depth (`vs_clear`, depth compare `Always`). Meshes are culled against each face's frustum. A slot is only re-rendered when its caster (light, shape, tiles) or the scene geometry signature (geometry generation + every mesh key and transform) changes, so static scenes cost nothing per frame. Faces (`LocalShadowFace`: VP + tile rect in atlas UV and its size in texels) go to `LocalShadowParams` (`local_shadow_params_id`), slot-major at `slot * 6 + face`. Reads `ShadowedLights` only to run after `light_upload`. **Glass tint maps**: every cascade (`glass_tint_id`, 1024² × 4) and every re-rendered local face (`local_glass_tint_id`, a 4096² atlas with the depth atlas's layout, its tiles cleared by `vs_clear` / `fs_clear_tint`), both Rgba16Float, get tinted after their depth: cleared to (1, 1, 1, 1e4), then `Blend` meshes drawn unculled with `vs_glass` / `fs_glass` (group 2 = their sRGB albedo, `glass_textures`), rgb blended by multiply (transmittance `(1 − coverage) + coverage × transmission × (1 − F)ⁿ × tint`, with Schlick Fresnel at the light's actual incidence angle (so curved clear glass gets dark rims) and n = 2 for thin-walled surfaces, volumes take the square root per face plus Beer–Lambert), a by `Min` (depth of the glass nearest the light: clip z for cascades, clip w for cube faces). Metallic is ignored. Glass never enters the depth maps. The instance buffer and the per-view uniform (`ShadowView`: view-proj + light direction (w = 0, cascades) or origin (w = 1, cube faces)) are visible to the fragment stage here |
| `gbuffer` | raster | camera, non-`Blend` meshes (frustum-culled by `MeshDraw::bounds`) | albedo (texture × base color factor × vertex color), normal, material (`Rgba8Unorm`: roughness, metallic, AO (always 1 for now), 0), emissive (`Rgba16Float`: texture × factor × strength, linear, unexposed), depth (reverse-Z, clear 0.0). Shadow visibility is a color: both the cascade lookup and `cube_shadow` multiply by `glass_tint` (group 2 bindings 5 / 6), which depth-tests each of 4 bilinear taps of the tint map against the receiver (cascade `ref_depth`, cube clip w minus one tint texel) so only glass in front tints. Point lights of size 0 use a fixed 1.5-texel PCF. Taps are clamped half a texel inside the tile, and `local_glass_tint` clamps its 4 texel loads to the tile too. A spot lookup outside its map is outside the cone and returns lit. Each tap compares against the receiver plane's depth under it (slope from two projected tangent points, capped at one kernel radius along the light ray), so wide kernels don't self-shadow; **no indirect specular**. `specular_weight` (Rgba8Unorm): rgb = Karis' analytic env BRDF, a = roughness; 0 on sky, debug views, or with Specular / Reflections / Indirect off, which also makes `ssr` and `composite` skip the pixel. `specular_fallback` (Rgba16Float): `reflected_radiance` × weight, exposed: the reflection probe (parallax-corrected: 4 fixed-point steps against its stored distance, mip = roughness × max LOD) once captured, else DDGI irradiance near the reflection vector |
| `ssr` | fullscreen (own pass, `ssr.rs`) | depth, normal, `lit`, `specular_weight`, camera, `lighting`'s debug flags uniform (`LightingOutputs::debug_flags_id`; `disable_ssr` writes zero confidence) | `ssr` (Rgba16Float): premultiplied hit color, a = confidence. First builds a pass-owned **Hi-Z pyramid** (R32Float, full mip chain, recreated on resize): `hiz.wgsl` (embedded) copies the depth into level 0 (`fs_copy`), then each level is the max (nearest, reversed-Z) of the 2×2 above, plus the extra row / column for odd sizes (`fs_reduce`). `ssr.wgsl` then traces in screen space with linear NDC z (≤64 cell visits, max 50 world units, clipped to the near plane and the screen edges, start 1–2 px out, IGN-jittered per frame): a cell the ray stays in front of is skipped and the trace goes up a level, otherwise down; at level 0 it hits when behind the depth by < 3 % of its distance. Readers earlier in the frame see last frame's copy; key bind groups on the generation |
| `ssr_temporal` | fullscreen (own pass, `ssr_temporal.rs`) | `ssr`, depth, `specular_weight`, camera | resolved SSR (Rgba16Float): reprojects the pass-owned history (last frame's output, copied with `copy_texture_to_texture`, cleared on resize) by the surface's own motion via `prev_view_proj`, clamps it to the 3×3 neighbourhood's mean ± 1.25σ (variance clip), and blends 10 % of the current frame, itself first clamped to its 8 neighbours' range so a single-pixel firefly can't enter the history. Sky / off-screen reprojection takes the current frame; zero weight writes zero. Ghosting under camera motion is untested (`capture` is static) |
| `composite` | fullscreen (`FullscreenPass`) | `lit`, `specular_weight`, `specular_fallback`, `ssr_temporal`'s output, G-buffer depth | final HDR: `lit + mix(fallback, weight × ssr, confidence)`, with SSR blurred by a 9-tap Vogel disc of radius `roughness × 32 px`. Taps are weighted by how well their depth fits the centre pixel's plane (reversed-Z depth is affine in screen space across a plane; gradient from the smaller one-sided differences), fading out between 1 % and 2 % of the depth, so reflections don't bleed across object borders or creases |
| `transparent` | raster (forward) | `composite` output, G-buffer depth, the same lights / clusters / shadows / probes / camera / debug flags as `lighting`, `Blend` meshes (frustum-culled) | final HDR (Rgba16Float): a fullscreen copy of `composite` (`fs_background`), then `Blend` meshes back to front by world-bounds center, premultiplied alpha, depth-tested (`GreaterEqual`) against a read-only G-buffer depth. Double-sided meshes draw back faces, then front faces. Uses `lighting.wgsl`'s `vs_forward` / `fs_forward` with groups 1–4 from `LightingBindings`, group 0 = G-buffer normal (binding 1), depth (binding 3), clamped trilinear sampler (4), scene texture (6), instance buffer (7, vertex + fragment), `t_behind` (8), group 5 = `MaterialTextures`. `t_behind` is the pass's own full-res mipmapped copy of the scene (recreated on resize), filled before the main pass with `fs_scene_copy` then `fs_scene_downsample` per level (group 0 = sampler 4 + source 10), on frames with a visible mesh whose transmission > 0, or with any visible blended mesh while SSR is on. **Glass through glass:** each mesh gets a padded screen rect from its projected world bounds (`ScreenRect`). Before drawing a transmissive mesh whose rect overlaps blended meshes drawn since the last copy, the pass ends, `t_behind` is rebuilt from its own output over the union of those rects only (scissored per mip, padded 2 texels per level), and the pass resumes with `LoadOp::Load`. At most `MAX_BEHIND_REFRESHES` (4) per frame; past that, glass sees the last copy. Non-overlapping meshes share a copy. Shading: base color alpha is coverage and scales diffuse + emissive; specular (direct, and probe reflections × env BRDF) stays at full strength; `transmission × coverage` of the scene behind passes through, tinted by the base color and minus the Fresnel reflectance; F0 for dielectrics comes from the IOR. The scene behind is sampled from `t_behind` at `refracted_uv`: thin-walled (thickness 0) sees straight through; volumes offset the lookup to where the refracted view ray exits after `thickness`, fading to straight-through near screen edges and rejecting pixels in front of the glass by depth. Its mip level grows with roughness (frosted glass), and volumes absorb by Beer–Lambert. Reflections: `reflected_radiance` (reflection probe or DDGI fallback, as in `lighting`) is blended with `glass_ssr`, a cheaper copy of `ssr.wgsl`'s march (32 steps, thickness test after refining the first crossing) against the G-buffer depth, which samples `t_behind` at a mip matching composite's roughness blur, then × env BRDF. Glass reflects opaque geometry only; opaque SSR still can't see glass. Draws nothing in G-buffer debug views |
| `debug_overlay` | raster | BVH, camera, probe params, debug flags | overlay texture (Rgba16Float): BVH boxes, probes, grid |
| `present` | fullscreen | `transparent` output + overlay | surface |

Coordinate conventions: right-handed, Y-up, camera looks down -Z. Light data is in **view space** on the GPU. Camera/GBuffer depth is reversed-Z (`GreaterEqual`, clear to 0). Shadow maps use standard Z (`LessEqual`).

## Light units
Lighting follows `KHR_lights_punctual`, so glTF intensities map 1:1. `SkyLight::intensity` is illuminance in lux, `PointLight`/`SpotLight::intensity` is luminous intensity in candela, and `AreaLight::intensity` is the emitter's luminance in nits. `lighting.wgsl` shades every light with one Cook-Torrance BRDF: GGX, height-correlated Smith visibility, Schlick Fresnel, `F0 = mix(0.04, albedo, metallic)`, diffuse `(1 − F)(1 − metallic)·albedo / π`. Perceptual roughness is clamped to `MIN_ROUGHNESS` (0.045) against fireflies. `probe_trace.wgsl` reflects light diffusely, with the triangle's specular reflectance folded into its albedo (see the pass table). Point/spot falloff is `window(d / radius)² / d²` (`range_attenuation`), so `radius` is the glTF `range`. The spot cone uses the spec's squared linear blend between `outer_cos` and `inner_cos`. The sky background (and the probes' sky term) scales with each sky light's illuminance. The camera's `exposure` (carried in `ClusterParams`) brings physical values into display range: 1.0 suits a few-lux scene, and daylight (~100 000 lx) wants roughly 2⁻¹⁵.

## Gotchas
- **Mesh geometry is keyed by `EntityKey`** in `GeometryArena`, and every mesh texture cache (`gbuffer`, `shadow`, `bvh_upload`) by `TextureAsset::id`, a process-unique counter. Never key a cache by `Arc` address: after a hot reload the new textures reuse the freed old addresses and the cache returns the wrong texture (`capture --reloads N` reproduces this). `SpritePass` still keys `SpriteTexture`s by `Arc` address. Changing a `Mesh`'s vertices in place is never re-uploaded, but replacing the entity (new key) works. `Mesh::transform` *is* picked up every frame. Removed meshes are freed on the next frame. `Mesh::material` factors go through `GpuModel` every frame, so they can be edited live. The DDGI BVH (`bvh_upload`/`probe_trace`) ignores alpha cutoffs, so cut-out geometry blocks GI rays as solid triangles. `Blend` meshes are invisible to everything but `transparent` and `shadow`'s glass tint maps: no depth, no opaque shadow, no GI occlusion (GI rays pass glass untinted), not reflected by SSR (they do reflect opaque geometry themselves, see `transparent`).
- Editing vertices in place at a constant mesh count leaves DDGI tracing stale geometry (the BVH only watches count and transforms). The same goes for material edits: per-triangle materials only refresh on a rebuild. Negative-determinant transforms (mirroring) flip winding and get back-face culled.
- "Main camera" is `get_entities::<Camera>().first()` in several passes. With multiple cameras, which one wins depends on slotmap order: after `World::clear`, freed slots are reused highest-first, so entities added later iterate *before* earlier ones.
- `lighting.wgsl` holds two paths: the deferred fullscreen `vs_main`/`fs_main` (group 0 = G-buffer, bindings 0–5) and the forward `vs_forward`/`fs_forward`/`fs_background`/`fs_scene_copy`/`fs_scene_downsample` used by `transparent` (group 0 bindings 1, 3, 4, 6–8 and 10 — reusing the deferred `t_normal`/`t_depth`/`s_linear` declarations at 1/3/4 — and group 5). Both share `direct_lighting`, `sample_probe_irradiance` and the BRDF helpers. A layout only needs the bindings its entry points use. A third set of entry points, `vs_probe` / `fs_probe_depth` / `fs_probe` / `vs_probe_sky` / `fs_probe_sky`, is the `reflection_probe` capture: group 0 bindings 7 (instances) and 11 (`ProbeCapture`, dynamic offset per face), groups 1–5 as the forward path. `direct_lighting(..., probe_capture)` then loops every point light (the camera's clusters don't apply) and takes the sky shadow from the first cascade containing the point, treating uncovered points as shadowed. Group 3 bindings 5–7 (reflection cube, `ReflectionProbeParams`, trilinear sampler) are part of `LightingBindings`. The forward path reuses `t_normal` (1), `t_depth` (3) and `s_linear` (4) with the same types; any other new group-0 binding must not collide with the other path's.
- WGSL structs/constants are duplicated by hand (no shader includes). Keep the Rust `#[repr(C)]` structs (`ClusterParams`, `ProbeGridParams`, `ShadowParams`, `CameraUniform`, `DebugFlagsGpu` (also declared in `ssr.wgsl`), `Gpu*Light`) and constants (`PROBE_GRID_DIM`, `PROBES_PER_ROW/COL`, `CLUSTER_*`, `NUM_CASCADES`) in sync with `sandbox/shaders/*.wgsl`.
- Only point lights are clustered. Spot (≤64) and area (≤32) lights are looped over for every pixel in `lighting.wgsl`, so keep their counts low. Area lights use a representative-point approximation (diffuse: closest point on the rectangle; specular: where the reflection ray meets it, with roughness widened by the equivalent disc radius, Karis 2013), are two-sided unless `two_sided` is false, and treat `right` / `up` as **half-extent** vectors. Only the up to 32 lights with a shadow slot cast shadows in direct lighting (atlas); all lights are shadowed in GI (`probe_trace`, BVH rays).
- The GBuffer stores **world-space** normals but local lights are in view space. `lighting.wgsl` converts the normal to view space (`N_vs`) for point/spot/area lights. Sky lights convert `L` to world space instead.
- `pass/sdf_voxelize.rs` is **not** in `pass/mod.rs`, so it is dead code. Wire it in or delete it.
- `Renderer::new` / `new_headless` use `adapter.limits()` and only the timestamp features the adapter supports. The GPU profiler activates only if `TIMESTAMP_QUERY | TIMESTAMP_QUERY_INSIDE_ENCODERS` are present.
- The surface (and the headless target) is sRGB, so passes output linear color. The egui overlay gets a non-sRGB view of the same texture.
- `Renderer::resize` ignores 0×0 sizes and clamps to `max_texture_dimension_2d`.
- `RenderDebugFlags` is shared by `Arc<RwLock>` between `DebugLayer` (render-thread UI), `ProbeAtlasPass`, `LightingPass` and `DebugOverlayPass`. To control it from outside, inject your own with `RenderGraphPBRBuilder::with_debug_flags` (the editor does this).

## 2D path (`rendering_2d`)
`SpriteRenderGraphBuilder` builds a single `SpritePass` that writes straight to the surface. A `SpritePass` can also be added to another graph as an overlay (pass `None` as the clear color). It sorts sprites by ascending `z_order` (painter's order), uploads all instances in one `FrameArena` allocation, and draws each run of consecutive sprites sharing a texture as one instance range (the cache is keyed by `Arc<SpriteTexture>` pointer). Instanced quads have per-instance TRS, color and `uv_rect` for atlases. `Camera2D { position, zoom }` gives an orthographic, Y-up projection in pixel units. The first `Camera2D` is used, or the default if there is none.
